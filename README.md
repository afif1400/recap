# Recap

Drop in a patient's scattered medical records — lab PDFs, scans, photos, discharge summaries. Get a chronological timeline + cited answers to plain-language questions.

Built for the [AMD x LabLab.ai Developer Hackathon](https://lablab.ai/ai-hackathons/amd-developer). Powered by **MedGemma** + **Qwen** running on **AMD MI300X** for the premium-mode demo.

**Not for clinical use.** Demo only. Synthetic patients only.
